# مشروع مذاكرتي بعد التقسيم إلى ملفات

تم فصل ملف HTML الأصلي إلى ملفات مستقلة مع الحفاظ على ترتيب JavaScript ومحتواه كما هو، لتقليل صعوبة الصيانة دون إعادة كتابة منطق التطبيق في هذه الخطوة.

## الهيكل

- `index.html`: هيكل الواجهة.
- `assets/css/main.css`: التنسيقات.
- `src/core.js`: الحالة والمنطق الأساسي.
- `src/timer.js`: عدّاد المذاكرة الحرة.
- `src/study-features.js`: ميزات المذاكرة وباقي واجهة الدراسة.
- `src/registration.js`: تسجيل المستخدم وبياناته.
- `src/admin.js`: بوابة الدعوة ولوحة المطور ووضع المشاهدة.
- `src/friends-chat.js`: الأصدقاء والرسائل.
- `src/account-cleanup.js`: تنظيف بيانات الحساب عند الخروج.
- `src/admin-cleanup-init.js`: تنظيف الحساب من جهة الإدارة وتهيئة التطبيق.

## مهم للبناء على GitHub Actions

إذا كان workflow الحالي ينسخ `index.html` وحده إلى `www/`، فلن تكفي هذه الخطوة بعد التقسيم. يجب نسخ المجلدين `src/` و`assets/` إلى `www/` أيضًا قبل `npx cap sync android`، مع الحفاظ على بقية خطوات البناء كما هي. لا تغيّر قواعد Firebase أو ترفع هذه النسخة قبل مراجعة القواعد واختبار تسجيل الدخول والرسائل على Firebase فعليًا.

## الاختبار المنفذ هنا

تم فحص تركيب كل ملف JavaScript باستخدام `node --check` والتحقق من أن جمع الملفات بالترتيب يعيد نص JavaScript الأصلي حرفيًا. هذا فحص تركيب فقط، وليس اختبار تشغيل داخل Android أو اتصال Firebase.
